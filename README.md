# Aplicativo Bancário com Swing e MySQL

Este é um aplicativo bancário simples com interface gráfica, desenvolvido em Java utilizando o framework Swing. A aplicação se conecta a um banco de dados MySQL para realizar operações bancárias essenciais.

Você pode assistir a este vídeo onde construo o app do zero, explicando passo a passo como ele funciona:  
[📺 Assista ao vídeo no YouTube](https://www.youtube.com/watch?v=phYuQWRaazw&t=1s)

## Funcionalidades

1. **Login na Conta**: Usuários podem acessar suas contas usando suas credenciais.
2. **Cadastro de Conta**: Novos usuários podem se registrar e criar uma conta bancária.
3. **Depósito**: Possibilidade de adicionar saldo à conta.
4. **Saque**: Permite a retirada de valores do saldo disponível.
5. **Consulta de Saldo**: Exibe o saldo atual da conta.
6. **Logout**: Encerra a sessão de forma segura.
7. **Histórico de Transações**: Mostra um registro de transações realizadas.
8. **Transferências entre Usuários**: Usuários podem transferir valores para outras contas cadastradas no banco de dados MySQL.
